## What the app does

Lean Playground teaches Lean 4, a programming language and proof assistant. Lean runs on your device: lessons, flashcards, labs, an editor where you build proofs with taps, and a code editor for your own files.

## Learning, not a guarantee

The lessons, cards and labs are for learning. When the app reports a proof as complete, it means that Lean accepted that code with the core library included in the app, and with Mathlib basics if the file imports Mathlib. It does not certify any real software, system or result outside the app. Check your own work before you rely on it. Lab simulations are illustrations with invented numbers.
